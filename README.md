# Student Management System

## About the Project

Student Management System is a Python-based project that helps manage student records using an SQLite database.

The system allows users to add, view, search, update, and delete student information.

## Features

* Add new student
* View all students
* Search student by ID
* Update student details
* Delete student
* Store student records in SQLite database

## Technologies Used

* Python
* SQLite

## Student Information

The project stores the following information:

* Student ID
* Name
* Age
* Course
* Marks

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
py student_management.py
```

4. Select an option from the menu.
5. Follow the instructions shown on the screen.
